# Sounds für BloxCraft Airlines BC-001

Die vier gelieferten Audiodateien sind bereits integriert. Sie liegen direkt in diesem Ordner und werden automatisch über die Sound-Konfiguration angesprochen.

| Datei | Funktion |
|---|---|
| engine-start.ogg | Einmalig beim Start des Triebwerks |
| engine-stop.ogg | Einmalig beim Ausschalten des Triebwerks |
| engine-loop.ogg | Dauerschleife, solange das Triebwerk läuft |
| radio-song.ogg | Dauerschleife im Radio-/Disco-Modus (R) |

Es gibt keinen separaten Nachbrenner-Sound. Der Nachbrenner bleibt stumm und nutzt nur die sichtbare Flamme.

Es wurde keine Bass-Datei mitgeliefert. Der Radio-Song wird trotzdem abgespielt; die Disco-Beleuchtung funktioniert unabhängig davon.

## Audio-Formate
Die gelieferten OGG-Dateien bleiben unverändert.
