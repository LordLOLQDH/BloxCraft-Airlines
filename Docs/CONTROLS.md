# BC-001 keyboard controls

| Key | Function |
|---|---|
| I | Engine start / stop |
| A | Afterburner toggle |
| H | Drop the three wheels |
| G | Deploy landing cushion |
| P | Emergency parachute |
| E | Simulate engine failure (also deploys parachute) |
| R | Radio / disco toggle |

The radio state is independent of the engine state. Sound files are not included yet.
